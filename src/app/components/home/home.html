PIPE TRANSFORMATIONS

Pipes in Action

Pipes transform values when displaying them in the template.

uppercase

{{ courseName | uppercase }}

Original: {{ courseName }}

titlecase

{{ courseName | titlecase }}

Converts text into title format.

currency

{{ price | currency:'INR' }}

Original value: {{ price }}

date

{{ today | date:'dd MMM yyyy' }}

Current date formatted using DatePipe.

custom pipe: shorten

This text is transformed using our own custom pipe.
